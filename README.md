# ZADM 随机点名系统

**ZADM**（子昂点名）是一个基于 Python Tkinter 的图形化随机点名工具，界面为浅色渐变动效风格，支持从 JSON 文件动态加载姓名列表，提供**滚动抽选**、**不重复抽签**、**名单管理**、**语法高亮代码查看**等实用功能，适合课堂互动、活动抽奖等场景。

---

## ✨ 主要特性

- 🎲 **随机滚动点名**：姓名高速滚动，点击“停止”后缓冲减速再定格，随机锁定一名成员
- 🚫 **不会重复抽到同一人**：内置「抽签袋」机制，一轮之内每人只出现一次；任何模式下都不会连续两次抽到同一人，结果与点击快慢、间隔完全无关
- 🌍 **中英文居中显示**：中文姓名、长英文名都会自动缩放字号，稳定居中在卡牌内
- 🎨 **浅色动效界面**：淡蓝渐变背景与漂浮星点、标题逐字浮动变色、卡牌呼吸描边、姓名滚动残影、结果弹跳 + 光环扩散 + 彩纸爆炸、按钮悬停辉光
- ⌨️ **快捷键**：空格 / 回车 同样可以开始或停止
- 📋 **可视化名单管理**  
  - 添加姓名：输入框里每行写一个姓名（也可以直接粘贴整列名单），点“添加姓名”一次加入，重复的自动忽略  
  - 添加后自动滚动到底部，并在状态栏提示新增 / 重复的数量
  - 点击整行勾选，支持全选 / 批量删除，勾选与悬停均有过渡动画
  - 列表支持鼠标滚轮滚动，长名单浏览无压力
- 📄 **内嵌代码查看器**  
  - 浅色主题语法高亮（关键字加粗，字符串 / 注释 / 数字分色）  
  - 实时读取并展示当前程序源码
- 💾 **JSON 数据持久化**：姓名列表保存为 `data/names.json`，结构清晰，可手动编辑
- 🖥️ **窗口控制**：主窗口固定尺寸、可自定义程序图标

## 🛠️ 运行环境

- **Python 3.6** 及以上版本
- **纯标准库**：`tkinter` `json` `os` `re` `math` `random`，无需任何第三方依赖

## 🚀 快速开始

### 1. 获取代码

```bash
git clone https://github.com/WZA-Leon/ZADM.git
cd ZADM
```
##2. 准备姓名数据
在 data/ 目录下创建 names.json（若不存在程序会自动生成默认名单），内容为 JSON 数组：
```json
[
  "张三",
  "李四",
  "王五",
  "赵六"
]
```
## 3.运行程序
```bash
python main.py
```
## 姓名管理窗口
-添加姓名：在上方输入框中输入姓名，每行一个，也可以直接粘贴多行 / 整列名单，然后点击“添加姓名”按钮一次全部加入；重复的姓名会自动忽略，结果在右下角状态栏提示，新加入的姓名会自动滚动到列表底部

-批量删除：勾选需要删除的姓名前的复选框，点击“删除选中”

-列表内容较多时，可使用鼠标滚轮流畅翻阅

## 代码查看器
-窗口自动显示 当前项目源码（main.py），并带有 VS Code Light 风格语法高亮

-文本只读，支持滚动查看，方便展示或检查代码

## ⚙️ 自定义配置
修改窗口图标：替换 data/zadm.ico 为你的图标

修改姓名文件路径：编辑 main.py 中的 json_path 变量（默认 data/names.json）

调整滚动速度：修改 main.py 中 roll() 里的 after(45, self.roll) 毫秒值

调整动画流畅度：修改 main.py 顶部的 FRAME_MS（默认 33 毫秒，约每秒 30 帧）

更改默认配色：修改 main.py 顶部的 BG_TOP / ACCENT / GOLD 等颜色常量
## ❓ 常见问题
Q：会不会总是抽到同一个人？
A：不会。程序使用「抽签袋」机制：一轮之内每个人只会被抽到一次，抽完才重新洗牌；并且任何模式下都不会连续两次抽到同一个人，抽选结果与点击的快慢、间隔无关。点击左上角“不重复”按钮可切换为纯随机模式。

Q：英文名字显示偏右怎么办？
A：姓名绘制在卡牌正中心（anchor 居中），过长时会自动缩小字号。若仍异常，请检查是否更改了 fit_size() 或 NAME_CX 相关代码。

Q：JSON 文件报错怎么办？
A：请检查 names.json 格式，必须为严格的 JSON 数组：姓名用双引号包裹，每个元素后用英文逗号分隔，最后一个后不加逗号。可使用在线 JSON 校验工具排查。

Q：鼠标滚轮在名单管理中无法滚动？
A：请确保 name_manager.py 已绑定 MouseWheel 事件（最新版已修复）。

Q：如何让窗口可调整大小？
A：编辑 main.py 的 ZadmApp.__init__，将 root.resizable(False, False) 改为 True（界面元素按固定尺寸排版，放大后可能需要自行调整坐标）。
