# ZADM 随机点名系统

**ZADM**（子昂点名）是一个基于 Python Tkinter 的图形化随机点名工具，支持从 JSON 文件动态加载姓名列表，提供**滚动抽选**、**一轮抽多人**、**历史均衡概率**、**特定人物概率**、**平均概率一键重置**、**四种界面主题**、**不重复抽签**、**名单管理**、**设置界面（密码保护）**、**语法高亮代码查看**等功能，适合课堂互动、活动抽奖等场景。

---

## ✨ 主要特性

- 🎲 **随机滚动点名**：姓名高速滚动，点击“停止”后缓冲减速再定格
- 👥 **一轮抽多人**：主界面左下角 `− n 人 +` 调整人数（1 ~ 10），卡牌滚动区域随人数自动变大，字号自动缩小，支持 1 ~ 4 列网格排布
- ⚖️ **历史自动均衡**：每次抽取结果都会写入 `data/history.json`，下次打开时按“谁被抽得少谁概率高”自动平衡，避免总是抽到固定的几个人
- 🎯 **特定人物概率（优先级最高）**：在设置里为个别人指定百分比概率，直接覆盖平均 / 均衡结果；该区域有独立密码（默认 `tr520`）
- ⚖️ **平均所有人概率**：设置里一键把概率恢复为完全平均（关闭均衡 + 清空手动概率），保存后会弹窗提示结果
- 🔐 **设置界面 + 密码**：抽选方式、人数、滚动频率、均衡强度、重置历史、主题、密码都集中在一个窗口；进入设置需要密码（首次进入时自行设置），也可以一键清空密码
- 🎨 **四种界面主题**：当前（默认浅蓝）/ 科技电路（深蓝电路 + 流光）/ 梦幻樱花（粉色 + 飘落花瓣）/ 极简三色（白底 + 红黄蓝）
- 🚫 **不重复抽签**：「抽签袋」机制，一轮之内每人只出现一次；人数允许时相邻两轮也不会抽到同一人
- 🌍 **自适应显示**：中文姓名、长英文名按格子大小自动缩放字号并居中
- 🎨 **动效界面**：渐变背景与主题装饰、标题逐字浮动变色、卡牌呼吸描边、姓名滚动残影、结果弹跳 + 光环扩散 + 彩纸爆炸、按钮悬停辉光
- ⌨️ **快捷键**：空格 / 回车 同样可以开始或停止
- 📋 **可视化名单管理**：多行批量添加（自动去重）、整行勾选、全选 / 批量删除、滚轮浏览
- 📄 **内嵌代码查看器**：浅色主题语法高亮，实时读取当前源码
- 💾 **JSON 数据持久化**：名单、设置、抽取历史分别存放在 `data/` 下，可手动编辑
- 🖥️ **窗口控制**：主窗口固定尺寸、可自定义程序图标

## 🚀 快速开始

### 1. 获取代码

```bash
git clone https://github.com/WZA-Leon/ZADM.git
cd ZADM
```

### 2. 准备姓名数据

在 `data/` 目录下创建 `names.json`（若不存在程序会自动生成默认名单），内容为 JSON 数组：

```json
[
  "张三",
  "李四",
  "王五",
  "赵六"
]
```

### 3. 运行程序

```bash
python main.py
```

> 首次点击右上角「设置」时会要求设置一个密码，之后每次进入设置都需要输入它。

## ⚙️ 设置界面

设置界面分为四个页签，点「保存并生效」立即生效，关闭窗口也会自动保存。

### 1. 抽选设置
- **不重复模式**：一轮抽完才重新洗牌
- **每轮抽取人数**：1 ~ 10（受名单人数限制）
- **姓名滚动频率**：1（慢）~ 10（很快），对应每 160 ~ 15 毫秒切换一次姓名

### 2. 概率设置
- **自动均衡**：根据历史次数调整概率
- **均衡强度**：0% ~ 200%，100% 为标准，越大越偏向“抽得少的人”
- **历史统计**：已记录轮数、总人次、最多 / 最少的人
- **平均所有人概率**：一键关闭均衡、清空手动概率，让所有人概率相等；点击后自动保存并弹窗提示
- **重置抽取历史**：清空后概率回到完全平均
- **平均概率**：显示当前“人人相同”时的百分比（1/N）

### 3. 特定人物概率（密码 `tr520`）
- 在“指定概率 %”里填数字，留空表示按均衡 / 平均自动计算
- “当前概率”列会实时预览设置后的实际概率
- 手动概率合计不能超过 100%；若手动值超过 100 会按比例归一
- 其他未手动设置的人，按剩余概率 + 均衡规则分配

### 4. 外观主题
- **当前（默认）**：浅蓝渐变 + 漂浮星点
- **科技电路**：深蓝科技底 + 电路走线与流光脉冲
- **梦幻樱花**：粉色渐变 + 飘落花瓣
- **极简三色**：白底 + 红黄蓝点缀
- 点主题右侧“使用”立即生效；抽选动画进行中会在下一轮开始时切换

### 5. 安全
- 修改设置界面密码（需要输入旧密码）
- **清空密码**：一键删除密码，之后进入设置不再需要密码；清空后也可随时重新设置密码

## 🎯 概率规则（优先级从高到低）

1. **特定人物手动概率**：直接按百分比固定，优先级最高，不受均衡 / 平均影响
2. **历史均衡**：权重 = `((历史总人次 / 人数 + 1) / (该人被抽中次数 + 1)) ^ 均衡强度`
3. **平均概率**：关闭均衡或强度为 0 时，所有人概率相同

举例：名单 10 人、历史里张三被抽中 5 次而其他人 0 次，则张三概率会明显低于其他人；若手动把张三设为 30%，则张三固定 30%，其余 70% 再由均衡规则分给其他人。

## 💾 数据文件

| 文件 | 作用 |
| --- | --- |
| `data/names.json` | 姓名名单（JSON 数组） |
| `data/settings.json` | 设置：人数、滚动间隔、不重复、均衡、主题、密码哈希、手动概率 |
| `data/history.json` | 每次抽取的记录：`{"time": "...", "names": ["张三"], "mode": "bag"}` |

> 密码以「随机盐 + SHA-256」形式保存，不存明文。忘记密码时，可在设置窗口「安全」页点「清空密码」，或直接把 `settings.json` 里的 `password_hash`、`password_salt` 改成空字符串。

## 🔧 自定义配置

- 修改窗口图标：替换 `data/zadm.ico`
- 修改姓名文件路径：编辑 `main.py` 中的 `json_path` 变量（默认 `data/names.json`）
- 修改每轮人数上限：编辑 `zadm_config.py` 中的 `MAX_DRAW`（默认 10）
- 修改特定人物概率区域的密码：编辑 `zadm_config.py` 中的 `MANUAL_PASSWORD`（默认 `tr520`）
- 调整动画流畅度：修改 `main.py` 顶部的 `FRAME_MS`（默认 33 毫秒，约每秒 30 帧）
- 更改主题配色：编辑 `zadm_theme.py` 中的 DEFAULT / CIRCUIT / SAKURA / MINIMAL 配色字典
- 修改主题列表：在 `zadm_theme.py` 的 `THEMES` 中增删主题（背景动画在 `create_decor` 中选择）

## ❓ 常见问题

**Q：会不会总是抽到同一个人？**
A：不会。程序使用「抽签袋」机制（一轮之内每人只出现一次），并且把每次结果写入历史；开启自动均衡后，抽得少的人概率更高。点击左上角“不重复”可切换为独立随机模式（仍不会连续抽到同一人）。

**Q：为什么相邻两轮可能有重复的人？**
A：当「每轮抽取人数 × 2 > 名单人数」时，无法保证相邻两轮完全不重叠，程序会优先抽上一轮没抽到的人。

**Q：忘记设置密码了怎么办？**
A：如果能进入设置，在「安全」页点「清空密码」即可；进不去时打开 `data/settings.json`，把 `password_hash`、`password_salt` 改成空字符串，并把 `password_protected` 设为 `false`，下次进入设置就不再需要密码（之后可重新设置）。

**Q：清空密码后还能再设置吗？**
A：可以。清空后「安全」页状态会显示“未设置密码”，直接填写新密码并点「设置 / 修改密码」即可重新开启密码保护。

**Q：主题在哪里换？**
A：设置 → 外观主题，点对应主题右侧的「使用」立即生效；正在抽选时会等这一轮结束、下一轮开始时切换。

**Q：想让所有人概率完全一样怎么办？**
A：设置 → 概率设置 → 点「平均所有人概率」，会关闭自动均衡并清空手动概率，保存后弹窗提示每人当前的概率。

**Q：特定人物概率的密码是什么？**
A：默认 `tr520`，可在 `zadm_config.py` 的 `MANUAL_PASSWORD` 里修改；输入错误 3 次会退出该区域。

**Q：手动概率总和超过 100% 会怎样？**
A：保存时会提示并拒绝；如果通过手动编辑 JSON 写入超过 100% 的值，程序会按比例归一（例如两人各 80% → 各 50%）。

**Q：英文名字显示偏右怎么办？**
A：姓名绘制在格子中心（anchor 居中），过长时会自动缩小字号。若仍异常，请检查是否更改了 `fit_size()` 相关代码。

**Q：JSON 文件报错怎么办？**
A：请检查 `names.json` 格式，必须为严格的 JSON 数组：姓名用双引号包裹，每个元素后用英文逗号分隔，最后一个后不加逗号。

**Q：鼠标滚轮在名单管理中无法滚动？**
A：请确保 `name_manager.py` 已绑定 MouseWheel 事件（最新版已修复）。

**Q：如何让窗口可调整大小？**
A：编辑 `main.py` 的 `ZadmApp.__init__`，将 `root.resizable(False, False)` 改为 `True`（界面元素按固定尺寸排版，放大后可能需要自行调整坐标）。
